## 协作消息与停止边界

0126 迁移新增协作消息和停止标记。消息只能发给同一用户、同一租户、同一运行树的成员；按调用 ID 幂等，单组限制消息数量和正文长度。在下一次模型边界读取，检查点保存已读 ID；读取后进程退出而尚未保存检查点时，会以相同消息 ID 重放。不会新增一轮独立模型调用，也不重写用量账本。

聊天侧栏的协作面板展示层级、状态、人工等待和消息送达，可发送引导或停止整组。工具提供 `subagent_tree`、`subagent_message` 和 `subagent_wait`。等待超时、部分完成和人工等待分别返回；失败/取消状态不会作为成功完成呈现。

派工、恢复与停止共享根运行的事务锁。并发名额在真正插入运行记录时复查；取消遍历所有后代，包含已完成中间节点下的活跃成员，不受 UI 的展示数量限制。原 `interrupted` 记录作为历史终态保留，停止标记阻止旧审批/恢复重新启动它。行锁读取强制刷新 ORM 缓存，防止迟到取消覆盖已经完成的状态。

实际验证：协作/原运行链/契约分组 107 passed；PostgreSQL 分组 7 passed，覆盖迁移重放与漂移、OAuth 并发刷新、并发派工、停止和插入竞争、迟到取消及旧等待点的恢复写入阻断。新增面板 ESLint 和 Vite 构建通过。真实模型、浏览器及成员人工审批全链路仍未验收。

## Public Session 身份与事务基础

0129 新增独立 APP、密钥、终端用户、Session、Input、Turn、执行关联、幂等回执、会话事件和文件草稿表。保留原 conversations/agent_runs 和 AgentRun 1.9；公开会话通过服务端标记阻止旧运行入口绕过队列。新表时间列使用 TIMESTAMPTZ；迁移补齐 0124–0129 新表及序列的 API 受限角色授权，readiness 同步检查新结构与预算函数。

APP Key 仅在新的公开认证适配层解析，不能作为产品登录凭据。APP 与外部用户 ID 决定独立无部门账号；客户端 X-App-Id 不授予权限。JWT 与个人 full/旧桌面 Key 不接受终端用户 Header，外部限权 Key 不能变成完整权限 Key。每次重新检查 APP、所有者、终端账号及租户成员资格。Agent 授权取 APP 清单与所有者当前可见范围交集，始终排除私有 Agent；知识范围取显式授权、当前所有者权限和 APP 租户交集。仅显式开启时可以委托所有者的模型凭据，不继承个人 MCP 或工作区权限。

终端用户与所有者共享日/月预算和并发预留，账本仍记录实际运行 UID。PostgreSQL 预算函数使用固定 search_path、事务身份校验和 SECURITY DEFINER，仅返回计数与用量汇总；不授予终端用户读取其他会话的权限。

接收与派发分开：接收保存完整有序消息、文件绑定及不可变回执；领取时在 Session 锁内一次提交 Input 消费、Turn、Run、正式消息和派发 Outbox。崩溃回滚后输入仍待领取，双 worker 只产生一次执行。模型/提示词/知识范围/审批模式在接收时冻结；执行重新验证权限。多条用户消息分别保存，worker 恢复原顺序、原 MIME 和完整图片 data URL，附件只绑定本次提交的末条消息。空闲队列支持 FIFO 和有界 steer 前缀合批；运行中接续见下面的收尾记录。

人工回答/工具审批恢复在同一 Turn 创建下一 Run，等待点消费、运行、Outbox 与控制回执同事务提交。审批先检查全部 call_id，再以 LangGraph checkpoint 保存决策；拒绝或参数变更不会执行工具。保留审批时绑定的原调用详情，worker 再次发布等待点不能覆盖。真实 SQLite checkpoint 关闭/重开验证通过；隔离 PostgreSQL 验证恢复回滚、旧等待点和改变幂等意图拒绝。

SSE 以 PostgreSQL 已提交事件为权威，支持跨 Turn 长期订阅和不透明 Last-Event-ID 游标。重连不重复执行输入；流式 item 与最终输出保持同一身份。每次事件读取重新验证凭据和作用域。断开连接时，短数据库事务完成关闭后再响应取消，避免污染连接池；等待期间不占用事务。只投影公开正文与协议事件，历史不会绕过来源门禁读取未发布的模型草稿。APISIX 已添加对应路由并关闭响应缓冲。

worker 注册公开 Session 作业和每五秒恢复扫描；Run、Outbox、输入消费与归属仍原子提交。运行中 steer 在完整工具批次后的模型安全边界交接，在同一 Turn 创建后续执行段。反复引导以首段作为协作血缘锚点，不消耗树的嵌套深度。DSH 保持受限运行配置，在完整模型轮边界接续；通用工具审批限于 LangGraph 后端，不擅自扩展 DSH 的工具权限。

取消等待执行停止后，通过 checkpoint 状态接口清理中断和未执行工具，不调用模型或工具；保留已完成的结果。待处理队列暂停，显式 continue 恢复；暂停后新输入优先单独执行。协作子任务在派发前注册自己的 Session/Turn，树停止也能到达父任务已经完成后的子任务。整树控制与派发统一先锁根 Session，并检查原冻结的深度和并发限制。

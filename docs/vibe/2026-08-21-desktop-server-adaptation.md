# 桌面端与 Yuxi 服务端运行契约适配

## 目标

- 桌面端只通过正式 AgentRun 链路提交问题并使用服务端最终 `output`，不维护第二套问答或检索逻辑。
- 每次运行把实际模型、冻结知识范围、检索来源与 Claim/Evidence 数量作为可审计上下文返回。
- 结构化服务端错误能够被桌面端原样识别，应用异常退出后可按原 `run_id` 恢复结果，不重复创建或计费。

## 契约

AgentRun 创建与结果响应增量返回 `run_context`：

- `protocol_version`：桌面适配协议版本。
- `model_spec`：本次运行冻结的实际模型。
- `knowledge_scope`：本次运行冻结的 Scope 版本、策略、检索模式和知识库成员摘要。
- `knowledge_retrievals`：同一 run 的轻量检索审计摘要，包括来源状态、关系/Claim/Evidence 数量、版本、警告和错误码。

该字段不包含 API Key、用户身份、完整 Claim/Evidence 正文或内部提示词。上下文加载失败不会影响最终答案读取。

## 验收清单

- [x] Agent Call 响应透传服务端运行上下文。
- [x] 桌面端最终答案与服务端 `output` 字符串完全一致。
- [x] 桌面端解析结构化 `error.message` 与错误类型。
- [x] 本地持久化服务端上下文并按会话展示。
- [x] 桌面端启动时按原 `run_id` 恢复未完成任务，不重新提交问题。
- [x] 旧版本地数据库通过增量迁移保留已有会话与消息。

# 本机文献文件夹完整入库

## 目标

知识库文件管理支持用户从本机主动选择单篇、多篇文献或整个文献文件夹，并通过现有后台任务完成上传、解析、分块和向量入库全流程。

## 边界

- 浏览器不能读取用户粘贴的任意 Windows 绝对路径；本机文件访问必须由系统文件或文件夹选择器授权。
- 服务端只保存文件内容、文件名和文件夹内相对路径，不保存 `C:\`、`D:\` 等绝对路径。
- 复用现有 MinIO、`add_documents`、解析器、知识库索引和任务中心链路，不新增旁路入库实现。

## 验收清单

- [x] 本机文件模式支持单选和多选受支持文献。
- [x] 本机文件夹模式递归上传并保留目录内相对路径。
- [x] 默认执行自动入库，任务顺序为上传、解析、分块、向量入库。
- [x] 任务结果包含提交、添加、解析、入库和失败数量及逐文件结果。
- [x] 上传期间不能切换模式或关闭弹窗，提交失败时弹窗不误报成功。
- [x] 浏览器相对目录不会写入 MinIO 对象键。

# 文献工作区与 PDF 知识源契约闭环

## 目标与边界

`/extensions` 的知识库继续拥有 PDF 原件、Source Contract、解析、质量门禁、索引和证据资格。
`/literature` 消费已激活的解析版本，仅生成阅读、译文、笔记、概念页和综述等派生产品。
不新增 PDF 摄入入口，不调用 Wiki build 代替论文编译，不把阅读修正或译文反向写成原始证据。

## 验收清单

- [x] PDF 激活事务同时写入 `literature_source_events`，即时登记失败可持久补偿。
- [x] 自动调用 keyword-only 阅读入队接口；补偿涵盖“已登记但没有阅读任务”。
- [x] HTTP、Agent、分页、图谱、概念、报告和资产下载继承知识源 ACL。
- [x] 当前来源必须仍是文件的活动解析；失效来源和删除/归档来源失败关闭。
- [x] 同 DOI 跨知识源不合并权限；同源重解析保留稳定文献身份。
- [x] 编译/翻译按来源解析、阅读修订、生成器版本区分任务和产物；旧结果不冒充当前结果。
- [x] 发布前重新检查来源版本与请求用户资格；处理中版本更新或权限撤销标记 STALE。
- [x] 双通道阅读任务按渲染版本调度、存储隔离；人工裁决重复回放不重复升级修订。
- [x] 阅读子进程实际分发离线/双通道入口，回传并上传复核清单；每次渲染使用不可变产物前缀。
- [x] 笔记 Wiki 按知识源分别发布，继承来源共享配置和所有者，并冻结来源版本。
- [x] 新来源激活时同事务撤销旧笔记 Wiki 发布；激活事务失败时恢复原发布指针。
- [x] 前端提供知识源回链、证据状态、阅读修订和历史任务提示。

## 迁移与兼容

迁移 `0079_literature_source_contract_closure` 增加冻结输入轴、报告来源清单和激活待办表。
无法证明出处的存量编译/翻译结果标记为 legacy，保留原文件和历史行，不猜测其对应当前解析。
这类结果需重新生成；没有来源清单的历史报告不向普通请求展示。
旧的租户级笔记 Wiki 清除当前发布指针，按来源重新构建；历史审计仍保留。
PaperAgent 新迁移的阅读包与笔记携带明确导入版本；不得覆盖既有科研 PDF 来源绑定。

## 验证方式

单元测试覆盖真实 PDF 编排入口、血缘校验、激活/待办同事务与登记入队；仅替换解析器和向量 I/O。
权限测试通过 ASGI HTTP 和真实 Agent 工具调用验证，不替换来源权限规则。
运行中的 E2E 验证真实 PG、MinIO、Redis/ARQ、离线阅读渲染与 HTTP 阅读入口。
外部 MinerU/Paddle/LLM 可用性与生产性能验收单独记录，不用打桩结果代替真实外部服务验收。

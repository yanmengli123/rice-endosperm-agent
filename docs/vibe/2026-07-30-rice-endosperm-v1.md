# 稻芯智析 V1 界面改造

## 目标

基于 Yuxi v0.7.1 建立“稻芯智析 · 水稻胚乳证据型科研智能体”的独立品牌界面，同时保持官方模板、核心聊天链路和上游更新路径清晰。

## V1 范围

- 建立可适配不同尺寸的独立品牌素材。
- 使用独立 YAML 加载名称、标题、Logo、头像、登录背景和页脚。
- 建立具有品牌根作用域的浅色、深色主题。
- 更新浏览器标题、favicon、首页和登录页。
- 用领域欢迎区替换通用随机问候。
- 推荐问题只填入输入框，不自动发送。
- 复用当前引用、文件、状态和智能体管理能力，不重构核心聊天链路。

## 不在 V1 实现

- 新建能力状态聚合接口。
- DAP/DAF 自动转换。
- E1–E5 证据等级。
- 永久三栏布局。
- 基因实体卡片和复杂知识图谱交互。
- 尚未具备的科研能力入口或状态承诺。

# 首页权威水稻数据库导航

## 目标

在稻芯智析公开首页增加可直接访问外部官方水稻数据库的科研导航，同时确保用户能够识别入口来源、适用场景和维护属性，不把历史资源误认为持续在线的生产服务。

## 实现范围

- 首页增加“权威水稻数据库导航”区块和页头锚点导航。
- 数据库元数据与页面组件分离，便于后续独立核验、增删和调整分类。
- 支持按数据库名称、机构、用途和关键词搜索。
- 支持核心门户、基因组与注释、表达与调控、变异与育种、功能与突变体、蛋白与通路、种质资源、官方归档分类筛选。
- 每个卡片展示维护机构、用途、关键词和入口状态，并在新标签页安全打开外站。
- 首屏只展示高频资源，允许用户展开完整目录；筛选或搜索时直接展示所有匹配结果。
- 提供核验日期、外站责任边界和版本引用提醒。

## 入口状态规范

| 状态 | 使用场景 |
| --- | --- |
| 官方入口 | 国家机构、国际组织或基础设施机构直接维护的入口 |
| 官方数据页 | 原独立服务可能不稳定，但仍由项目官方资源页提供的数据入口 |
| 研究资源 | 由论文作者或高校科研团队建设和维护的专业数据库 |
| 官方归档 | 已进入机构长期归档、主要用于历史数据追溯的资源 |

状态只描述入口来源和维护属性，不承诺目标网站的实时可用性。外部站点的许可、引用、隐私和服务状态由对应机构负责。

## 数据维护约定

1. 优先保留 HTTPS 和目标机构当前公开的规范地址。
2. 旧 MSU 域名统一指向 UGA RGAP；SNP-Seek 使用 IRIC 官方数据资源页。
3. 同一数据库只保留一个主卡片，其他研究用途通过关键词覆盖，避免重复入口干扰用户。
4. 页面不加载外部 Logo、脚本或追踪资源，降低版权、隐私、性能和供应链风险。
5. 每次发布前抽查精选入口，并更新 `RICE_DATABASE_LAST_VERIFIED`；失效入口降级为研究资源、官方数据页或归档，不静默替换到非官方镜像。

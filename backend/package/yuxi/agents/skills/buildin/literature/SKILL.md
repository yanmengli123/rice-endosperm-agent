# 文献库技能

当用户问题涉及**文献库**（bib 导入的论文、知识库解析的 PDF、L1/L2/L3 编译笔记、
译文、依附资料、引用网络）时，使用本技能的工具。文献笔记与译文是**导航/阅读
派生物**：可用于理解与扩展检索，但**不得**作为回答的证据引用——证据只能来自
知识库权威源（由知识检索链给出 evidence_id）。

## 可用工具

- `search_literature_papers`：按标题/DOI 检索本租户文献库，返回元数据（类型/期刊分区/价值分），不返回正文。
- `read_compiled_note`：读取文献的 L1/L2/L3 编译笔记状态与逻辑 URI（kbasset），正文经资产端点获取。
- `list_paper_attachments`：列出文献的依附资料（支撑信息/审稿意见/数据；用户原始资料）。
- `get_citation_neighbors`：返回文献的引用邻居与共被引分簇（计量导航）。
- `request_paper_translation`：**写操作**——为文献请求翻译（异步任务）；需本轮执行计划允许，被拒绝时向用户转述拒绝原因，不要重试。

## 操作流程

1. 文献类问题先 `search_literature_papers` 定位文献（rid）。
2. 需要"这篇论文讲了什么"→ `read_compiled_note` 取 L1 笔记；需要方法论批判/跨文献关系 → L2/L3。
3. 用户问支撑数据/审稿细节 → `list_paper_attachments`。
4. 用户问"谁引用了它/相关文献" → `get_citation_neighbors`。
5. 用户明确要求翻译 → `request_paper_translation`（一次即可，任务入队后告知用户稍后在文献库查看）。

## 边界

- 文献未编译 L1 时，如实告知"未编译"并建议在文献库页触发编译，不要编造笔记内容。
- 翻译请求被计划门禁拒绝时，转述原因（写操作需冻结计划），不要绕过。
- 本技能工具不接受 kb_id/租户参数——范围由运行上下文决定。
